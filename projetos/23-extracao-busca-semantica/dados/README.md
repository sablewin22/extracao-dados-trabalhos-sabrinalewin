`noticias_lula_flavio_2026.csv` é uma seleção didática fechada de 40 matérias de outubro de 2026: dez por veículo e foco. Contém título, resumo publicado pela fonte, data, URL e texto de análise formado por título + resumo. Não inclui os artigos completos. Os links permitem auditoria, mas a contagem das linhas não representa o volume de cobertura total de cada veículo. Seleção e metadados verificados em 13/10/2026.
