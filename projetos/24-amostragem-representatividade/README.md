README

**Intruções:**

> Abra o notebook exercicio-24-amostragem.ipynb no Google Colab ou execute localmente, criando um ambiente com uv venv .venv e instalando as dependências com uv pip install -r requirements.txt. Execute as células de cima para baixo, sem pular etapas.

**Fonte:**

> Os dados do eleitorado são simulados no próprio notebook, utilizando uma semente baseada nos quatro últimos dígitos da matrícula. Também foi utilizada a ficha técnica de uma pesquisa eleitoral real registrada no PesqEle, do Tribunal Superior Eleitoral (TSE).

**Limitações da análise:**

> Como o eleitorado utilizado nas primeiras partes é simulado, os resultados servem para demonstrar conceitos de amostragem, margem de erro, viés de seleção e ponderação, não para prever resultados eleitorais reais. A ponderação por faixa etária também não garante a correção de todos os vieses, pois podem existir diferenças entre as pessoas que respondem e as que não respondem dentro de cada grupo. Na análise da pesquisa real, a margem de erro representa apenas a incerteza amostral e não elimina possíveis problemas relacionados ao método de coleta, à seleção dos participantes ou à representatividade da amostra.
